A guide for readers

How the evidence is organised

Start with the context and focus of each set, then follow the actions, supporting evidence, and reflection. The standards section connects the examples to the relevant professional focus areas.

What will each document include?

Each set includes the supplied artefact reflections, standards connections and selected source excerpts. Supporting images and tables appear alongside the relevant text.

Can I download the original documents?

Yes. Each evidence page includes a link to the original Word document, preserving its supplied layout and supporting material.
